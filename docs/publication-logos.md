# Publication source logos

These original logos identify the source of a manuscript or contribution in the compact library rows. Assets were retrieved on November 25, 2026, from the organizations' public websites and saved without image edits. CSS controls their displayed size and preserves their aspect ratios.

The PNG/JPEG assets were verified as valid image files. The Research Square SVG contains no scripts, event handlers, external references, embedded images, or `foreignObject` elements.

Source logos identify the host of the linked version, rather than indicating publication status. For example, DeepEXPOKE is in press at Genome Medicine, while its currently linked public version is the medRxiv preprint.
